# M5 T-032 / T-033 落地设计（只读调研产出）

> 由子代理 `agent-1` 于 2026-11-27 产出，供 lead 在第二轮评审修复合并后实施。本文是设计记录，不是验收报告。

## 1. T-032 状态模型

- 以 `serializeGraph()` 产出的 `GraphIR` 为快照单位；`undoStack` / `redoStack` 两个数组，栈深 100，`push` 时截断 redo。
- **入栈时机（commit 边界）**：节点增删、连线增删、控件值提交、节点拖动结束、绑定变更成功、load 图各算一次事务。
  - 控件提交边界见 `apps/web/src/controls/react.tsx:116-150`（Number）、`apps/web/src/controls/react.tsx:136-166`（Text）、`apps/web/src/controls/react.tsx:260-320`（Pose）、`apps/web/src/rete/nodeRenderers.tsx:156-164`（Script）；只在 `commitText` / blur / `Ctrl+Enter` 回调里 push，`onChange` 的每次 keystroke 只更新本地文本与 `control-error`。
  - 位置：在 area 的 `translate` / `nodetranslated` 结束事件 push 一次（debounce drag end），不要每帧 push。
  - 绑定：只在 `apps/web/src/App.tsx:308-321` 的 `handleBind` 返回 `ok` 后、以及 `handleUnbind` 后 push。
- **不入栈**：连接状态/statusDetail、toast（含 `binding.toast` 8s 自动清）、缩放与 LOD 状态、`selectedPort`/节点选中态、Script 运行报错、纯 `refresh()` 引起的 `graph` state 更新。
- **撤销恢复 runtime 绑定**：不要复用 load 的 catch 回滚路径（`apps/web/src/App.tsx:239-261` 缺 `runtimeBindings` 消费，正是第二轮 P1-A）。统一走一个 `restoreSnapshot(ir)`：`clearDynamicRegistrations()` → `loadGraph()` → `registerDynamic()` → 遍历 `result.runtimeBindings` 调 `bind()` → `setSelectedPort(null)` / `setLastGain(null)` / `refresh()`。恢复期间用 `restoringRef` 抑制 `onControlChange` 与 toast，`restoreSnapshot` 内部绝不 push history；undo/redo 需串行化，避免与在途 `loadGraph` 重叠。

## 2. T-032 与 save/load 的复用边界

- `serializeGraph()`（`apps/web/src/rete/serialize.ts:48-70`）纯读，可安全用于快照。
- `loadGraph()`（`apps/web/src/rete/serialize.ts:122-176`）破坏性，副作用必须显式处理：
  - `editor.clear()`（:143）清掉全部节点/连线；`clearDynamicRegistrations()` 由调用方负责。
  - 节点 id 被 `Object.defineProperty` 保留（:130-140），边 id 不恢复（:167-174 新建），Script 只恢复 `code` 不恢复 `x`（`apps/web/src/rete/nodes.ts:259-277`）。
  - 成功路径会 ROS `bind()` 并弹 toast（`App.tsx:219-227,247`），undo 时必须静默。
- 最小方案：**快照用 `serializeGraph`，恢复用 `loadGraph` 的单一 `restoreSnapshot`，不要为撤销另写序列化器**。
- **复制粘贴**：从当前 `GraphIR` 取选中节点深拷贝，节点 id 置空后交给 `createNode` / `editor.addNode`（`apps/web/src/rete/editor.ts:70-82`）让 Rete 生成新 id；位置 `+40/+40`；只复制两端都在选中集合内的边，边 id 不保留。值恢复用 `applyParamBinding()`（`apps/web/src/rete/nodes.ts:152-179`），Script code 用 `:272-277`；**不要复制 `toParamBinding` 里的 ROS 绑定**，避免重复订阅。
- 「选中节点」最小语义：editor handle 增加 `selectedNodeIds: Set<string>`，`nodepicked` 与 Ctrl+点击 toggle 维护；与现有 `selectedPort`（`App.tsx:63-73`，绑定面板用）分离。LOD 分支 placeholder 选中态（P2-C）把同一集合桥到视觉，不要各搞一套。

## 3. 快捷键与控件冲突

- 挂载点：`App` 的 editor `useEffect`（`apps/web/src/App.tsx:75-146`）里 `window.addEventListener('keydown', onKeyDown)`，`editor.destroy()` 时移除；回调从 `handleRef.current` 取 handle，避免重建画布。
- 判断要点：
  - `if (e.defaultPrevented) return;`（控件 capture 阶段已 swallow 空格，见 `apps/web/src/controls/react.tsx:22-46`）。
  - `const t = e.target as HTMLElement; if (t.isContentEditable || /^(INPUT|TEXTAREA|SELECT)$/.test(t.tagName) || t.closest('[data-testid^="pose-"]')) return;`
  - `if (!(e.ctrlKey || e.metaKey)) return;`
  - `key==='z' && !e.shiftKey` → undo；`key==='z' && e.shiftKey` 或 `key==='y'` → redo；`key==='c'` → copy；`key==='v'` → paste。仅当实际处理时 `preventDefault()`。
  - Script textarea 的 `Ctrl/Cmd+Enter` 由自身 `onKeyDown stopPropagation`（`apps/web/src/rete/nodeRenderers.tsx:156-164`）处理。
- Rete 核心没有 undo/redo API（`apps/web/node_modules/rete/_types/editor.d.ts:46-115` 只有 add/remove/clear），area 的 `selectableNodes` 也不绑 Ctrl+C/V；无需禁用内置撤销，但要确认 LOD 分支未引入自定义快捷键。

## 4. T-033 toast 统一

现有失败出口清单：
- `apps/web/src/App.tsx:247` 加载后部分绑定失败、`:259` 回滚兜底、`:268` 加载异常、`:285`/`:289`/`:297`/`:302` 扩展名/8MB/非法 JSON/读取失败、`:313`/`:317` 类型不兼容/绑定失败、`:331` ParamBrowser 类型拒绝。
- `binding.toast` 来自 `apps/web/src/binding/useParamBinding.ts:498-502`，源头是 controller 的 `onError`：类型不匹配（:180）、写入被拒/异常（:199/:205）。
- 非 toast 但需保留的 inline 错误：`control-error`（`apps/web/src/controls/react.tsx:81-85`）、`script-error`（`apps/web/src/rete/nodeRenderers.tsx:165-167`）、`param-error`（`apps/web/src/ParamBrowser.tsx:144,253-255`）。它们不应进 ros-toast（e2e 明确断言 `ros-toast=0`）。

最小方案：
- 加纯函数 `formatFailure({ kind, param, reason })`（建议 `apps/web/src/toast.ts`），仅负责拼文案并保证参数名形如 `Gain.gain`：绑定/写入/类型错误统一带 `nodeType.portKey`；`ParamBrowser` 的 `onTypeReject` 文案补上参数名（`apps/web/src/ParamBrowser.tsx:299-304` 目前没有）。
- App 里把所有 `setLocalToast(...)` 替换为同一个 `pushToast(formatFailure(...))`；`binding.toast` 继续由 hook 的 8s 自动清除管理，渲染仍用 `apps/web/src/App.tsx:483-487` 的 `binding.toast || localToast`。
- **不要做**：不改 `data-testid="ros-toast"` / `role="alert"` / `.ros-toast` class；不删 `useParamBinding` 的 8s timer；不把 `control-error` 合并进 toast；不大改 binding hook 接口。
